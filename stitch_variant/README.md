# Variante de Diseño Stitch: Dame Clic

Esta carpeta contiene el código fuente completo y el asset visual generado directamente desde **Google Stitch** para el proyecto de **Dame Clic** (Agencia de Marketing Digital en Costa Rica).

---

## 📁 Archivos incluidos:
* **`index.html`**: Código fuente HTML completo generado por Stitch con diseño responsivo, Tailwind CSS integrado, tipografía *Plus Jakarta Sans* e *Inter*, soporte para Mega Menú de servicios y paleta corporativa.
* **`screenshot.png`**: Captura en alta resolución (2560 x 14244 px) del diseño completo generado por la IA de Stitch.

---

## 🚀 Cómo previsualizarlo en el navegador:

### Opción 1: Abrir el archivo directamente
Haz doble clic sobre el archivo `index.html` en tu explorador de archivos (Finder) o ábrelo directamente en Google Chrome, Safari o tu navegador preferido.

### Opción 2: Desde el servidor local activo
Si el servidor HTTP de desarrollo está activo en el puerto `8080`, puedes acceder directamente en:
👉 **`http://localhost:8080/stitch_variant/index.html`**
